## 🥋 About the Developer

Hi! I'm **Alex (Oleksandr Siholaiev)** — a karate athlete and software developer.

I built **FourEver** because I needed a native, distraction-free interval clock that stays completely out of the way during intense training sessions. Zero ads, zero user accounts, zero subscriptions — 100% focused on performance and privacy (100% offline with zero analytics and zero tracking).
